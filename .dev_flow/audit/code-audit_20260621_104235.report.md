## Clean / well-handled (covered, no action — so coverage is auditable)
- **Expression evaluator** (`Expr`/`ExprParser`): pure recursive-descent arithmetic over a fixed function table — no `eval`/`Function` passthrough.
- **Circuit-string → HTML/JS injection:** all circuit-controlled text renders via canvas `Graphics.drawString`; `new HTML(...)`/`setInnerHTML` use compile-time constants. No XSS via circuit data.
- **`executeJS` ScriptInjector sink:** all callers pass static strings / internal numerics — no circuit/query data reaches it.
- **Solver numeric safety net** (`CircuitSimulator`): `sanitizeStampValue` clamps ±1e12 & maps NaN/Inf→0 with `converged=false`; `stampResistor` guards `r==0`; 3-level panic ladder force-advances instead of throwing — consistent with RULE_ERR_001/002. `stampCircuit` wraps each `stamp()` in try/catch → `stop()`.
- **`CircuitMath.lu_factor/lu_solve`:** singular-pivot guard `<1e-14`, correct n==0/1 edges, correct pivot/back-substitution indexing.
- **`ElmGeometry`:** all `dn`-normalization guarded by `dn==0`.
- **Scope ring buffers:** `scopePointCount` always power-of-two; indexing via `& (scopePointCount-1)`; no off-by-one.
- **Text importer:** per-line try/catch+log (a malformed line doesn't abort the file) — contrast the JSON path (CF-04).
- **Secrets / RNG:** no hardcoded credentials in Java client source; `RandomUtils` used only for simulation noise.
