## 📋 Top plan items (priority desc)

### ITEM-02 — Add a Content-Security-Policy and constrain NW.js Node integration  ⟶ `standard`
- **Findings:** CF-02 (SEC-02) — defense-in-depth for the **untrusted circuit-file surface** (ITEM-07). No longer tied to remote-debug (ITEM-01 is settled by design — DEC_01).
- **Severity:** should *(re-graded from must — its headline driver, capping the remote-debug `eval`, is resolved by design; residual rationale: a malicious `.cjs`/URL circuit must not be able to escalate a future DOM/JS-injection bug to host code execution).*
- **Affected:** `war/package.json` (no `webkit.csp`), `out/linux-*/…/package.nw/package.json`, `war/circuitjs.html` (no `<meta>` CSP). Node already used at [LogManager.java:124-126,214-215,246,266](../../src/main/java/com/lushprojects/circuitjs1/client/LogManager.java#L124).
- **Fix direction:** add a restrictive `webkit.csp` / `<meta http-equiv="Content-Security-Policy">` (`script-src 'self'`, `connect-src` loopback only); consider isolating Node usage behind a narrow bridge instead of page-wide node integration.
- **Verify:** app still launches and all in-app scripts load under the CSP; `fs` logging still works; external/eval script loads are blocked.

### ITEM-03 — Fix `StringTokenizer` start-index so legacy text `# description` parses correctly  ⟶ `standard`
- **Findings:** CF-03 (COR-01) · **active data-corruption bug**
- **Severity:** must
- **Affected:** [StringTokenizer.java:74,185,206](../../src/main/java/com/lushprojects/circuitjs1/client/StringTokenizer.java#L74) (field `start` shadowed by a local, accessor returns always-0); consumer [CircuitElmCreator.java:267-272](../../src/main/java/com/lushprojects/circuitjs1/client/CircuitElmCreator.java#L267).
- **Why:** `getStartTokenIdx()` always returns 0, so `readDescription` does `substring(0+1)` and stores the **whole dump line** as the element description; the corruption round-trips back out on save.
- **Fix direction:** assign the **field** in `nextToken()` (`start = pos;` not `int start = pos;`), or derive the offset from `getEndTokenIdx()` − token length. Confirm `getStartTokenIdx()` returns the real token start.
- **Verify:** text round-trip (RULE_TEST_003) of a circuit with `# comment` descriptions over the `public/circuits/` corpus; description survives import→export unchanged.
- **Note:** L0 shared primitive — re-check the few other `getStartTokenIdx()` callers (if any) when fixing.

### ITEM-04 — Isolate per-element failures in JSON import (don't abort the whole file)  ⟶ `standard`
- **Findings:** CF-04 (COR-03), with CF-06 (COR-02) as a concrete trigger
- **Severity:** should
- **Affected:** [JsonCircuitImporter.java:142](../../src/main/java/com/lushprojects/circuitjs1/client/io/json/JsonCircuitImporter.java#L142) (over-broad top-level `catch` abandons remaining elements/scopes/adjustables), unguarded `isNumber()` derefs at [CircuitElementFactory.java:555-556](../../src/main/java/com/lushprojects/circuitjs1/client/io/json/CircuitElementFactory.java#L555) (reached from `:338/:351/:365`) and `JsonCircuitImporter.java:444,477`.
- **Why:** one element with a non-numeric pin/bounds coordinate NPEs out of `createFromJson`, bubbles to the file-level catch, and silently drops the entire circuit — contrary to RULE_ERR_003 (importers skip-and-log, don't abort).
- **Fix direction:** null-check `isNumber()` before deref (skip/return null on a bad coordinate); wrap each element create in a per-element try/continue that logs and skips, instead of relying on the file-level catch.
- **Verify:** JSON round-trip corpus; a hand-broken element loads the rest of the circuit + logs the skip.

### ITEM-05 — Clamp `TransLineElm.ptr` on JSON restore to prevent an out-of-bounds crash  ⟶ `trivial`
- **Findings:** CF-05 (COR-04)
- **Severity:** should (uncaught exception reaching the UI)
- **Affected:** [TransLineElm.java:391](../../src/main/java/com/lushprojects/circuitjs1/client/element/TransLineElm.java#L391) (`ptr` restored unbounded), used at `:236,250,265` inside `startIteration` (called from `CircuitSimulator.runCircuit:1487`, no try/catch).
- **Why:** `lenSteps`/buffer length is recomputed in `reset()`; a saved `ptr >= lenSteps` (delay or timestep changed since export) → `voltageL[ptr]` AIOOBE → uncaught crash on load.
- **Fix direction:** `ptr = (lenSteps > 0) ? (getJsonInt(...,0) % lenSteps) : 0;`.
- **Verify:** load a transmission-line circuit with a stale/oversized stored `ptr`; no crash.

### ITEM-06 — Fix `SparkGapElm` JSON state serialization (self-reference + bad cast)  ⟶ `trivial`
- **Findings:** CF-06 (COR-02)
- **Severity:** should
- **Affected:** [SparkGapElm.java:192,201](../../src/main/java/com/lushprojects/circuitjs1/client/element/SparkGapElm.java#L192) (`state.put("state", state)` stores the map in itself; read casts the nested Map to `Boolean` → CCE on import).
- **Fix direction:** `state.put("state", this.state)` on write; guard the type before casting on read.
- **Verify:** save/load a circuit with a SparkGap; fired/unfired state survives and the file loads. (Closing CF-04/ITEM-04 also stops this CCE from nuking the whole file.)

### ~~ITEM-07~~ — Treat URL-supplied circuits as untrusted (no silent auto-run)  →  **DEMOTED → BL-AR (2026-06-21)**
> Demoted by developer decision: WONTFIX under DEC_01 (localhost-only / operator-initiated). Auto-running a circuit is the same operator-controlled deep-link class as the accepted remote-debug `eval`, carries no code-execution sink (audit clean-areas confirmed no parsed-string → DOM/JS path), and `?cct`/`?running` is a documented deep-link/E2E feature. Re-raise only if the app is exposed beyond localhost. No code change made.
- **Findings:** CF-07 (SEC-04)
- **Severity:** should · theoretical today (no current parsed-string → code/HTML sink — see report "clean areas")
- **Affected:** [CircuitInfo.java:76-94](../../src/main/java/com/lushprojects/circuitjs1/client/CircuitInfo.java#L76) (`cct`/`ctz`/`running`/`startCircuit` from URL), consumed at [CirSim.java:323-347](../../src/main/java/com/lushprojects/circuitjs1/client/CirSim.java#L323), `decompress` via `$wnd.LZString` at `:139-141`.
- **Why:** a crafted link auto-imports and can auto-run an attacker circuit with no confirmation; bounded today, but a one-click escalation if any element ever routes a parsed string into a DOM/JS sink (given ITEM-02 not yet fixed).
- **Fix direction:** do not honor `running=1` from a URL-supplied circuit without a prompt; add a regression check asserting no element serializes parsed circuit strings into HTML/JS.
- **Verify:** opening a `?cct=…&running=1` link prompts before running.
