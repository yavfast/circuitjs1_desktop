## Description

_[main]_ `/dev-flow fix BL-DROP`. Root cause: the JSON exporter writes `elm.getJsonTypeName()` as the element `"type"` ([JsonCircuitExporter.java:237](../../src/main/java/com/lushprojects/circuitjs1/client/io/json/JsonCircuitExporter.java#L237)); `CircuitElementFactory.createFromJson` looks that name up in `JSON_TYPE_TO_CONSTRUCTOR` ([:318](../../src/main/java/com/lushprojects/circuitjs1/client/io/json/CircuitElementFactory.java#L318)). For 20 element types the emitted name has no matching registration → the element is silently dropped on import (count loss, no exception). The audit only sampled 3 (TransLine/Sweep/Switch); the full class is 20.
